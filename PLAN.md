# Ballast — План реализации

> «See past the daily swing»
> Дневник веса и ИМТ, где главное — не показание весов, а тренд: фильтр Калмана
> отделяет воду/соль/время взвешивания от реального изменения, учит ваш
> обычный разброс и сдвиги по дням недели, честно отвечает «когда при таком
> тренде» и проверяет цель против ВАШИХ же ограничений.

## 0. Архитектура

Полностью локально, `expo-sqlite`, сети нет (INTERNET заблокирован).
Разрешения: `POST_NOTIFICATIONS` (одно утреннее напоминание, только по явному
включению, пропускается, если сегодня уже взвешивались), `RECEIVE_BOOT_COMPLETED`,
`VIBRATE`. Не медицинский советчик: цель и предел темпа задаёт пользователь,
приложение только проверяет их согласованность; ИМТ — справочно, с оговоркой.
Тема светлая, шрифт заголовков и чисел — Manrope. Вес хранится в кг, единицы —
только отображение (kg/lb, cm/ft·in).

## 1. Движок (`src/lib`) — цепочка

1. `trend.ts` — **накапливаемая модель**: фильтр Калмана «локальный линейный
   тренд» (уровень + скорость, интегрированное блуждание скорости) с
   наблюдением y = уровень + w[день недели] + шум. Обновляется ОДНОЙ записью на
   каждое новое взвешивание (состояние хранится в settings.model). Учит:
   R — ваш разброс от дня ко дню (инновация² − дисперсия прогноза, априор +
   забывание), w[0..6] — сдвиги по дням недели со сжатием к нулю и
   центрированием. Правка/удаление/взвешивание задним числом — пересборка из
   журнала; смена констант — `MODEL_VERSION` → пересборка при старте.
2. `projection.ts` — конус прогноза (90%) и **распределение срока до цели**
   по выборке (уровень, скорость) из апостериора с корреляцией; P(тренд идёт к
   цели). Детерминированный сид — сценарии сравниваются без шума.
3. `goal.ts` — статусы reached / onTrack / behind / conflict; конфликт: нужный
   темп выше вашего лимита, дедлайн прошёл, тренд уверенно в другую сторону.
   **Выходы, проверенные пересчётом**: ближайший дедлайн на вашем лимите,
   промежуточная цель к дедлайну, дедлайн по темпу тренда, без дедлайна
   (последним). Темпы — с двумя знаками (0.63 против 0.5).
4. `whatif.ts` — «если держать такой темп» (подмена скорости), сдвиг дедлайна,
   сдвиг цели → две колонки.
5. `explain.ts` — «почему весы показали столько»: тренд до взвешивания +
   сдвиг дня недели + шум в единицах вашего разброса, насколько сдвинулся тренд.
6. `tags.ts` — метки («поздний ужин», «солёное»…): разница остатков с меткой и
   без, 90% интервал Уэлча, вывод только при ≥ 3 и интервале вне нуля.
7. `body.ts`, `stats.ts` — ИМТ/единицы, недельные изменения тренда, время в
   категориях ИМТ, частота взвешиваний, серия, heatmap.

Тесты: 11 (`engine.test.ts`) + образец шаблона: восстановление скорости и
шума на синтетике, обучение сдвига понедельника, плато, ETA против наклона,
конфликт цели и проверка выхода, what-if, выброс, метки, статистика.

## 3. Экраны (6)

1. **Calendar** (`index`) — Calendar-first: тренд сегодня (AnimatedCounter) +
   категория ИМТ, строка цели, календарь месяца (точка — отклонение от тренда,
   свайп — месяц); тап по дню без записи — шторка взвешивания с этой датой,
   с записью — карточка дня. Первый запуск — карточка «рост и единицы».
2. **Day** (`day/[date]`) — master-detail: взвешивания дня, инлайн-правка веса,
   «почему весы показали столько» с разложением, метки и заметка, свайп-удаление.
3. **Trend** — график с жестом-скрабом (палец по графику — значение любого дня
   и прогноза), конус и линия цели, плитки, шкала ИМТ, сдвиги дней недели.
4. **Goal** — Goal / What if: цель (пресеты от тренда и по ИМТ), дедлайн,
   предел темпа, статус с причинами, выходы с Apply; сценарии в две колонки.
5. **Stats** — 7 секций; тап по дню недели фильтрует разброс и метки.
6. **Settings** — рост/единицы, напоминание, вибрация, «как это работает», сброс.
